# Тренировки: 14 недель

Мобильный трекер тренировок и веса на 14 недель: прогрессия весов, таймер отдыха, журнал и питание.
Один файл `index.html`, без сборки и серверов.

## Где хранятся данные

В базе браузера (IndexedDB) на том устройстве, где открыто приложение. Копия состояния дублируется в localStorage.
Данные не уходят на сервер и не синхронизируются между устройствами.

Раздел «Журнал» → «Резервная копия»:
- **Экспорт** сохраняет JSON-файл со всеми тренировками и замерами.
- **Импорт** объединяет файл с текущими данными (нужно для переноса на другой телефон).

Делай экспорт раз в пару недель: очистка данных сайта в браузере удалит и базу.

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Приложение откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

На телефоне открой ссылку и добавь страницу на главный экран.
